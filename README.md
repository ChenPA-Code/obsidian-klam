# Obsidian-klam

> 把和 AI 对话中值得留档的内容，自动整理成结构化 Obsidian 笔记，按项目归档。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Obsidian](https://img.shields.io/badge/Obsidian-Ready-7C3AED.svg)](https://obsidian.md/)

---

## 它解决什么问题

和 AI 的大量对话里藏着决定、待办、学习收获、资料、灵感、产出物，但对话是"一次性"的——关掉就丢了。

**Obsidian-klam** 在对话结束时，把值得留档的内容提取出来，写成规范的 Obsidian 笔记，沉淀进你的知识库，后续可搜索、可关联、可回顾。

---

## 核心特性

| 特性 | 说明 |
|---|---|
| **对话沉淀** | 扫描本轮完整对话，提取有长期价值的内容 |
| **按项目归档** | 笔记归入 `Projects/<项目名>/`，自动维护项目索引 `_index.md` |
| **自适应结构** | 不强制固定分类——按对话性质组织小节，模块按需组合，可缺省、可自建 |
| **直接写入** | 预览确认后直接写入正式笔记目录（`status: reviewed`），无暂存区 |
| **幻觉缓解** | 原文引用 / 宁缺毋滥 / 推断标注 / 预览确认，四层机制控制幻觉风险 |
| **零配置** | 技能放进库内自动识别 `.obsidian` 定位库，无需手动配置路径 |
| **多库支持** | 每库放一份即写哪个库；或用 `VAULT_PATH` / `init.sh` 切换 |
| **幂等防重** | 同一会话重复触发提示「更新 / 跳过」，不会重复生成 |

## 工作流程（7 步）

```
① 确认项目名 → ② 扫描会话 → ③ 去噪 → ④ 提取内容（自适应结构）
→ ⑤ 预览确认（人工门）→ ⑥ 直接写入 Projects/<项目>/ → ⑦ 更新项目索引
```

- 第 ⑤ 步：向你展示待写入清单，**你确认后才写入**；
- 第 ⑥ 步：笔记直接写入 `Projects/<项目名>/`（`status: reviewed`）；
- 第 ⑦ 步：刷新 `Projects/<项目>/_index.md`。

## 快速开始

### 1. 安装

把 `obsidian-klam/` 文件夹放入你的 AI 助手的 skills 目录，或直接放进你的 Obsidian 库内部（推荐，见下方零配置）。

### 2. 配置（零配置推荐）

**为什么需要配置？** 技能要把笔记写进你的 Obsidian 库，而库就是一个本地文件夹——它必须知道"库文件夹在哪"。Obsidian 打开的库会自动生成隐藏的 `.obsidian` 目录（相当于"我是 Obsidian 库"的身份证），技能就靠识别它来定位库根。

| 方式 | 操作 | 是否"即用" |
|---|---|---|
| **零配置（推荐）** | 把 `obsidian-klam/` 放进你的 Obsidian 库内部（如 `你的库/.agent/skills/`） | ✅ **放进去即用**——自动识别 `.obsidian` 定位库 |
| **一次配置** | 运行 `scripts/init.sh` 输入库路径 | 一次操作（技能包在库外时用） |
| **临时覆盖** | `export VAULT_PATH=/你的/库路径` | 需要操作（多库切换/测试时用） |

#### 零配置原理

```
你的库/                      ← Obsidian 库根目录（含 .obsidian 身份证）
├── .obsidian/               ← 身份证（Obsidian 自动生成）
└── .agent/
    └── skills/
        └── obsidian-klam/   ← 解压后把整个文件夹放在这里即可
```

技能工作时会从自己所在位置**一层层向上查找**，直到发现 `.obsidian`，即认定该目录就是库根，自动往 `你的库/Projects/<项目名>/` 写入。所以：**只要技能在库内，库叫什么名字、在哪个盘都不用管，无需任何配置。**

#### 多库使用

**新建任何库都会自动生成 `.obsidian`**，所以多库完全支持。技能认哪个库，按以下优先级：

```
1. VAULT_PATH 环境变量        → 临时指定，最优先
2. 向上探测：技能在哪个库内     → 就认哪个库
3. ~/.config/obsidian-knowledge.conf（init.sh 写的配置）
4. 常见位置探测
```

| 你的用法 | 推荐方式 |
|---|---|
| 长期用主库 | 技能放主库内 = 零配置，永远写主库 |
| 偶尔切到别的库 | `export VAULT_PATH="/新库路径"` 临时覆盖 |
| 常换库、想记住 | 跑 `./scripts/init.sh` 改一次配置指向新库 |

**实用建议**：技能包很小，每个常用库都可以放一份——放进哪个库就写哪个库，互不干扰。

### 3. 使用（触发）

直接对 AI 说以下任意表达都会触发：

> 「**整理这轮对话**」「**沉淀到 Obsidian**」「**记到 Obsidian**」「**记录要点**」「**保存结论**」
> 「**写入笔记库**」「**存档**」「**留档**」「**归纳一下**」「**把有用的记下来**」
> 「**做个笔记**」「**知识沉淀**」「**记笔记**」「**整理聊天记录**」「**把对话存下来**」

可加项目名，如：「沉淀到项目 Obsidian-klam」。

```
Vault/
└── Projects/<项目名>/

    └── 2026-09-07-<标题>.md   # 预览确认后直接写入（status: reviewed）
```

正文小节从模块库按需组合（**对话是什么样就按什么样组织，允许缺省/混合/自建**）：

`背景与事实` / `关键决定` / `行动项` / `学习要点` / `资料与链接` / `灵感与想法` / `待讨论问题` / `产出物` / `原话摘录`

## 幻觉控制（诚实说明）

**会，无法完全消除**——AI 提取必然存在幻觉风险。本技能用四层机制把风险压到可控：

1. **原文引用**：每条目附来源（用户原话 / 消息序号），方便逐条核对；
2. **宁缺毋滥**：对话里没有、无把握的内容一律不写，不确定数字标「（待核实）」；
3. **推断标注**：AI 推断的内容强制标「（推断）」；
4. **预览确认门**：写入前展示清单、你确认后才落盘；写入后建议抽查关键条目。

**结论**：技能负责"降低并暴露"幻觉，最终把关靠你的审核——不要直接信任 AI 写的原文。

## 注意事项

1. **敏感信息硬拦截**：token / API key / 密码 / 密钥 / 证件号 / 手机号 / 银行卡等**一律不写入**；如需留档，只写脱敏后的替身值（如 `sk-***`）。
2. **写入前必须确认**：默认交互模式，未经你确认不写任何文件。
3. **写入后抽查**：AI 笔记可能含幻觉，预览确认后再落盘；落盘后建议抽查关键条目，别直接信任。
4. **幂等防重复**：同一会话重复触发会提示「更新 / 跳过」，不会重复生成。
5. **内容结构不设限**：按对话实际内容组织，允许混合/缺省/自建小节。
6. **超长对话会精简**：内容过多时先分层摘要，超限时只写「结论 + 行动项」精简版。
7. **写入失败不丢失**：写入失败时整理结果完整保留在回复中，不会静默丢弃。
8. **文件名安全**：标题中的 `/ \ : * ? " < > |` 会被自动替换，不会产生非法文件名。
9. **别手动改脚本**：路径配置通过 `init.sh` 或环境变量完成，改脚本会导致升级时冲突。

## 目录结构

```
obsidian-klam/
├── SKILL.md                    # 技能入口：名称、触发词、工作流
├── README.md                   # 本文件
├── LICENSE                     # MIT 协议
├── .gitignore
├── references/                 # 规则文档（AI 执行时读取）
│   ├── extract-rules.md        # 什么内容值得写 / 什么必须拦截
│   ├── note-schema.md          # 笔记模板：目录、属性、命名
│   └── project-moc.md          # 项目索引（_index.md）维护规则
└── scripts/                    # 可执行脚本
    ├── config.sh               # 库路径解析（自动找库）
    ├── init.sh                 # 一次性配置库路径（可选）
    ├── write_note.sh           # 生成笔记文件
    └── check_duplicate.sh      # 幂等查重（防止重复写入）
```
